# Alain

Desarrollador freelance especializado en automatización, integraciones y aplicaciones prácticas de IA para negocios. Con base en Asturias, España — trabajo con alcance nacional.

## Sobre mí

Antes de dedicarme al desarrollo, pasé cerca de una década en hostelería. Esa experiencia operativa me da una perspectiva poco habitual en perfiles técnicos: entiendo cómo funciona un negocio por dentro antes de automatizarlo.

Hoy diseño y despliego sistemas que resuelven problemas operativos concretos en pymes — seguimiento de leads, automatización de procesos, integraciones entre herramientas que no se hablan entre sí.

## Stack

- **Automatización:** n8n, Docker, APIs, cron
- **Backend / scripting:** Python, JavaScript, Bash, Java
- **Web:** WordPress, Astro
- **Infraestructura:** Linux, self-hosted, Cloudflare
- **IA aplicada:** integración de modelos de lenguaje en flujos de negocio reales
